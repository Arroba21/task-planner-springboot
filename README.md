 Spring Boot + Calendar

Aplicación full-stack para gestionar tareas con calendario.  
Permite crear tareas con hora de inicio y fin, visualizarlas en un calendario interactivo y moverlas mediante drag & drop.

## Tecnologías utilizadas

Backend
- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

Frontend
- HTML
- CSS
- JavaScript
- Bootstrap
- FullCalendar

Control de versiones
- Git
- GitHub

# Funcionalidades

- Crear tareas con título, descripción y horario
- Visualizar tareas en un calendario semanal o mensual
- Arrastrar tareas en el calendario para cambiar la hora
- Marcar tareas como completadas
- Eliminar tareas
- API REST para gestión de tareas
